        七、字段口径

        • tier / tierName：信源等级（数字 id 与展示名），参与「信源可信度」打分。
        • spec：可验证参数行（参数规模 / 上下文 / 定价 / 许可 / 跑分），参与「可验证度」打分。
        • date：只有月份可考时写 YYYY-MM，显示为该月，不虚构具体日期。
        • 重要度分数：不写死在数据里，由 meta.scoring 的规则实时算出，改规则即全库重算。

        八、如何更新数据

        • 打开同目录的 data.js，这是唯一数据源。
        • 按现有字段往 items 追加新条目，id 保持唯一，填好 tier，重点事实补 spec。
        • 修改 meta.updatedAt 为新的检索日期；想调整评分口径只改 meta.scoring。
        • 保存后刷新页面即生效。时效打分以数据中最新的日期为基准，不依赖系统时间。

        九、已具备的工具能力

        • 公司 / 动态类型 / 信源等级 / 时间范围 多维筛选，全文搜索与关键词高亮。
        • 按重要度（单列榜单，默认前 10 条、可逐层展开）与按时间（按日）两种组织方式。
        • 每条可展开「评分依据」核对 A/B/C/D 四项得分；标题直达原文；当前结果导出 CSV（含分数与各项得分）。
